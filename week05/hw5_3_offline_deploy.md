# W5课后作业3：乡村学校无网教室离线部署方案

如果要在没有网络的乡村学校教室部署本地 AI 备课助手，我会这样准备：

## 1. 离线包准备（提前在有网环境做好）
- 提前下载好 Ollama Windows/macOS 离线安装包，拷贝到U盘；
- 提前 `ollama pull` 好要用的模型，模型文件默认存在用户目录下，
  连同整个 models 目录一起拷到U盘，到现场直接导入，不用现场拉取；
- 同时把 Python、requests 等依赖的离线 whl 包一起备好，防止现场缺库。

## 2. 模型选择
按学校机房常见配置（8GB 内存）选 qwen2.5:0.5b 或同量级 1.5b 模型，
不要尝试 4b 以上，8GB 内存跑 4b 会卡死。
量化档固定 Q4_K_M，体积和质量平衡最好。
用途定位：学生作文语法检查、课堂临时出题、术语解释，不追求复杂推理。

## 3. 内存预算
- 系统本身占用约 2–3GB；
- 浏览器、备课软件预留 1–2GB；
- 留给模型 2–4GB，刚好跑 0.5b–1.5b 档；
- 现场关掉多余软件，用 `ollama ps` 盯内存占用；
- 一次只跑一个模型，不要同时加载多个。

## 4. 现场兜底
- 提前在自己电脑上跑通一遍完整流程，截图保存每一步；
- 准备一个写好的 Python 脚本，双击就能调用本地模型，不依赖命令行；
- 万一 Ollama 服务起不来，现场手动 `ollama serve`，并用 curl 验证 11434 端口。
