# 课后作业3
任务：预习第8周阶段项目「学科智能问答助手 v1.0」，设计项目目录结构，列出待补齐功能

## 项目目录结构
week08_qa_assistant/
├─ llm.py                 # 复用week06双引擎统一调用入口
├─ rag_qa.py              # 复用week07 RAG检索问答逻辑
├─ main.py                # 程序入口，交互循环，接收用户输入问题
├─ data/
│   └─ subject_text.txt  # 学科知识库原始文本材料
├─ chroma_db/             # 向量数据库，gitignore忽略不上传
├─ weekpath.py            # 路径工具、读取环境变量
└─ .gitignore             # 排除向量库、环境密钥文件

## 需要补齐实现的功能清单
1. 简易交互循环：支持控制台反复输入问题，不用每次重新运行脚本。
2. 优化来源展示：回答之后清晰展示引用的资料片段与来源。
3. 增加建库开关：更换知识库文本时，支持参数控制是否重建向量库。
4. 异常捕获：处理文件缺失、ollama未启动、网络异常，给出友好提示。
5. 参数兼容：保留prefer="local"/"api"，继承双引擎自动回退能力。
6. 输入过滤：对用户空输入做判断拦截。
