# W4课后作业1：精读DeepSeek API文档
## temperature
temperature控制模型输出的随机发散程度，取值范围0‑2。数值越低输出越确定重复；数值越高创造性越强，但更容易产生幻觉。做教学解释、出题建议取0.2‑0.7。

## max_tokens
控制模型最大输出token上限。到达上限会直接截断回答，不是模型出错；设置合理值可以防止输出过长，同时控制调用费用。

## timeout
请求超时时间，网络环境差时调大；校园网抖动容易触发超时报错，超时代表请求没有完成，不会产生计费。

## 更换平台需要修改的两处
1.base_url接口地址；2.model模型名称。其余调用代码可以复用，得益于OpenAI兼容接口。
